# Module 6 Bonding Review

A study site for Honors Chemistry 2, Module 6: bonding and intermolecular forces.

- **Plan**: day-by-day schedule and review checklist up to the Module 6 exam
- **Videos**: all 25 Khan Academy videos grouped by class day, with summaries
- **Models**: 3D VSEPR shapes with dipoles, electronegativity table, lattice energy comparer, formal charge checker, σ/π counter, IMF comparer, hydrogen bonding, vapor pressure and phase diagrams
- **Quiz**: 125 practice questions with explanations and a missed-question list
- **Flashcards**, **Notes**, **IMF lab** data and a **cheat sheet**

It is a single `index.html` file with no build step. Open it in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to get a live link.

Progress (checkboxes, quiz history) is saved in your browser's local storage only.
